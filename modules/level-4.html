Creating a Floor Plan Using StructDraft

LEVEL 4 LESSON

LESSON: Creating a Floor Plan Using SructDraft

Learning Objectives

At the end of the lesson, students should be able to:

Create a basic floor plan using SructDraft.

Draw walls, doors, and windows.

Add room labels and dimensions.

Materials Needed

Computer or laptop

AutoCAD software

Floor plan measurements

Procedure

Step 1: Open SructDraft Open SructDraft and create a new drawing.

Step 2: Set the Units Type UNITS and choose the appropriate measurement, such as millimeters or meters.

Step 3: Draw the Walls Use the LINE or PLINE command to draw the exterior walls. Use OFFSET to create wall thickness.

Step 4: Create Room Divisions Draw interior walls to divide the house into different rooms.

Step 5: Add Doors and Windows Create openings using TRIM, then draw the doors and windows in their proper locations.

Step 6: Add Dimensions Use the DIMENSION command to show the measurements of the floor plan.

Step 7: Add Room Labels Use TEXT or MTEXT to label each room, such as Bedroom, Kitchen, and Living Room.

Step 8: Finalize the Drawing Check the measurements, line quality, and arrangement. Save the completed floor plan.

Important AutoCAD Commands

Command

Function

LINE (L)

Draws lines

OFFSET (O)

Creates parallel lines

TRIM (TR)

Removes unnecessary lines

MOVE (M)

Moves objects

COPY (CO)

Copies objects

DIM

Adds dimensions

TEXT

Adds labels

Summary

AutoCAD makes floor plan drawing easier and more accurate. By using commands such as Line, Offset, Trim, Dimension, and Text, students can create a clear and properly measured floor plan.
