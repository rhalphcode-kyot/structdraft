Creating a Foundation Plan Using AutoCAD / StructDraft

LEVEL 5 LESSON

LESSON: Creating a Foundation Plan Using AutoCAD/SructDraft

Learning Objectives

At the end of the lesson, students should be able to:

Create a basic foundation plan using AutoCAD/SructDraft.

Identify the location of columns and footings.

Add foundation dimensions and labels.

Materials Needed

Computer or laptop

AutoCAD software

Building floor plan and measurements

Procedure

Step 1: Open the Floor Plan Use the floor plan as a reference for the location of walls and columns.

Step 2: Create the Foundation Layout Draw the foundation lines based on the building layout.

Step 3: Add Footings Use the RECTANGLE or LINE command to draw the footings at the required locations.

Step 4: Add Columns Draw the columns above or at the center of the footings.

Step 5: Draw Foundation Walls or Footing Beams Use LINE and OFFSET to create the required foundation connections.

Step 6: Add Dimensions Use the DIMENSION command to show the sizes and distances of the foundation components.

Step 7: Add Labels and Symbols Label the footings, columns, and other foundation parts.

Step 8: Check and Finalize Check the alignment, measurements, and accuracy of the foundation plan before saving.

Important AutoCAD Commands

Command

Function

LINE (L)

Draw foundation lines

RECTANGLE (REC)

Draw footings

OFFSET (O)

Create parallel lines

COPY (CO)

Copy similar objects

MOVE (M)

Move objects

DIM

Add measurements

TEXT/MTEXT

Add labels

Summary

A foundation plan shows the location and arrangement of the building's foundation, including footings, columns, and foundation walls or beams. AutoCAD helps create an accurate and organized foundation drawing.
